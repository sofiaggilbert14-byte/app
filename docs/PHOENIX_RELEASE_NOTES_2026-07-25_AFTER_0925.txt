CharmIPTV Phoenix Universal Beta
Release Notes
Date: July 25, 2026
Scope: Changes made after the APK build from approximately 9:25 AM

Summary
-------
This update focuses on stability, guide navigation, mobile safety, player overlay reliability, layout polish, build versioning, and tester-facing settings. The biggest improvements are safer guide scrolling, better mobile behavior, safer live preview controls, automatic build/version display, optional automatic channel numbers, optional channel logo loading, a TV/mobile layout preference, and a black/gold Settings redesign.


New Features Added
------------------
1. Safe Preview Mode setting

Added a new setting under Settings -> Guide & Player Preferences:

- Live preview ON
- Live preview delayed
- Live preview OFF

Behavior:

- Live preview ON changes the live preview immediately when a channel is highlighted.
- Live preview delayed waits briefly before changing the live preview. This is now the safer default for testers.
- Live preview OFF keeps the guide/details active but prevents the live preview video from playing while browsing.

Reason:

This helps prevent crashes or stutters when scrolling quickly through the guide on lower-powered Android TV boxes, Onn boxes, Fire Stick devices, and phones.


2. Guide Density setting

Added/updated Guide Density choices in Settings:

- Comfortable
- Normal
- Compact

Behavior:

- Comfortable uses larger rows for easier reading across the room.
- Normal balances readability and number of visible guide rows.
- Compact shows more guide rows on screen.


3. Automatic build/version display in Settings

Settings now displays the installed app build/version instead of relying on a hardcoded text label.

The displayed version comes from the app configuration used to build the APK.


4. Automatic APK version stamping

The GitHub APK build workflow now automatically stamps each APK with a new version number based on the GitHub run number.

Example APK filename:

CharmIPTV Phoenix Universal BETA v2.0.123-beta.apk

This makes it easier to know exactly which APK testers are using.


5. Channel Numbers setting

Added a new Settings toggle:

- Channel numbers ON/OFF

Behavior:

- When enabled, Phoenix automatically numbers the current full channel lineup.
- If channels are added or removed, the numbers automatically recalculate from the latest loaded channel list.
- Numbers are based on the full sorted channel lineup, not just the current tab.

Channel numbers were added to:

- Main guide
- Box/card guide
- Favorites
- Recently watched
- Search results
- Quick Picks
- Player channel strip
- Current playing channel title area


6. Channel Logos setting

Added a new Settings toggle:

- Channel logos ON/OFF

Behavior:

- When enabled, Phoenix loads normal channel logos.
- When disabled, Phoenix uses initials/fallback logo blocks instead of loading logo images.

Reason:

This gives testers a quick way to reduce image loading and visual/network work on weaker boxes if scrolling or loading feels heavy.

Channel logo disabling applies across:

- Main guide
- Box/card guide
- Favorites
- Recently watched
- Search results
- Quick Picks
- Player channel strip
- Current preview area


7. Device Layout Mode setting

Added a new Settings choice:

- Auto
- TV
- Mobile

Behavior:

- Auto chooses the safest layout based on the device.
- TV forces the TV/Command Center style layout.
- Mobile forces the mobile-safe card layout.

Reason:

Some Android devices behave differently than expected. This gives testers and users a way to manually choose the layout that works best on their device.


Fixes and Stability Improvements
--------------------------------
1. Mobile orientation and half-screen resize fix

Improved mobile behavior when rotating between portrait and landscape.

Fix target:

- App sometimes filled only half the screen after rotating.
- App sometimes crashed after rotating and pressing Back.
- App sometimes crashed immediately after reopening following a rotation crash.


2. Mobile Safe Guide

Added a safer mobile guide path for non-TV Android/mobile devices.

Behavior:

- Phones use a card/box guide instead of the full TV-style timeline/live-preview guide.
- The A-Z rail is hidden on mobile.
- Mobile layout avoids the live active preview while browsing.

Reason:

This reduces rotation issues and prevents mobile touch/scroll behavior from fighting the TV-focused guide layout.


3. Preview ratio fix

Fixed the live active preview box so video stays closer to the proper 16:9 shape.

Adjustment:

- Preview box is now less wide.
- Details/description area gets more width.
- Video preview should look less stretched.


4. Auto-scrolling program descriptions

Added automatic scrolling for long program descriptions.

Behavior:

- If the description fits, it stays still.
- If the description is too long, it slowly scrolls upward.
- When it reaches the end, it returns to the top, pauses briefly, then repeats.
- The scroll resets when the user highlights another channel/program.


5. Guide focus navigation stabilization

Improved D-pad/remote behavior in the timeline guide.

Fix target:

- Guide sometimes jumped back up to the category tabs.
- Guide sometimes would not let the user get back into the guide area after moving up to the menu/category tabs.

Changes:

- Removed forced focus behavior that kept preferring the first guide row.
- Made guide channel cells and program cells explicitly focusable.
- Added nested scrolling support for the timeline area.


6. Favorites/category tab stability

Hardened behavior when switching tabs/categories and when opening Favorites.

Fix target:

- Favorites tab sometimes crashed after adding channels.
- Some category tabs sometimes crashed or behaved inconsistently.

Changes:

- Removed forced first-card focus from the box/favorites grid.
- Added category safety so the app falls back to All if the selected category becomes invalid.


7. Fast guide scrolling crash mitigation

Added delayed guide preview switching.

Fix target:

- Holding Down on the remote to scroll quickly through the guide could crash the app.

Behavior:

- Guide focus/highlight can move quickly.
- Live preview waits briefly before changing streams.
- This prevents the preview player from trying to load many streams rapidly during fast scrolling.


8. Player overlay hook warning fix

Cleaned up React Hook warning in the player screen.

Fix target:

- GitHub Actions warning:
  React Hook useEffect has a missing dependency: 'scheduleHide'.

Changes:

- Stabilized player overlay timer functions.
- Removed hook warning suppressions around player timer/back-button behavior.
- Player overlay hide/show behavior should be more predictable.


9. Settings toggle focus fix

Reworked Settings toggles so they can be reached and changed with a TV remote/D-pad.

Fix target:

- Some Settings switches/buttons were skipped while scrolling with the remote.
- Users could see the setting but could not focus it to turn it on/off.

Changes:

- Replaced skipped native switches with focusable selectable rows.
- Added visible ON/OFF pills.
- The full setting row can now be selected with the remote.

Affected settings:

- Channel numbers
- Channel logos
- Auto retry streams
- Pointer mode


Removed or Reduced
------------------
1. Removed forced first-item focus behavior

Removed from:

- Timeline guide first row
- Box/card grid first item

Reason:

This behavior could pull focus back to the top unexpectedly and contribute to crashes or navigation traps.


2. Reduced live preview aggressiveness

The guide no longer instantly switches preview streams during rapid guide scrolling.

Reason:

Rapid preview switching was a likely cause of crashes during fast remote scrolling.


3. Reduced optional logo loading

Channel logo loading can now be disabled from Settings.

Reason:

This can improve performance on low-powered devices or connections where loading many logos makes the app feel heavier.


Layout and UI Adjustments
-------------------------
1. Live preview/details layout adjusted

- Live preview uses a more natural video ratio.
- Description panel is wider.

2. Live preview increased by 20%

Adjusted the Command Center preview/details row:

- Normal row height increased from 150 to 180.
- Compact row height increased from 110 to 132.
- Short-screen row height increased from 126 to 151.

Behavior:

- Live preview is larger.
- Video remains in a proper 16:9 shape instead of stretching.
- Description panel automatically narrows to make room.
- Description panel matches the preview height.


3. Mobile layout adjusted

- Mobile avoids the A-Z rail.

Changes:

- Gold/white text treatment.
- Stronger TV focus glow.
- ON/OFF pill styling for toggle rows.
