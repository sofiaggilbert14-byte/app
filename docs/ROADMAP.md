# CharmIPTV Phoenix Roadmap

## Current milestone

Phoenix Closed Beta (`2.0.0-beta.1`)

## Priorities

1. Stability on Android TV and Fire TV
2. Fast cached startup and bounded memory use
3. Predictable D-pad navigation and playback controls
4. Release diagnostics and reproducible Android builds

## Closed Beta scope

- [x] VLC playback and Android TV launcher support
- [x] Favorites, search, reminders, and recently watched
- [x] Bounded EPG parsing window
- [x] Remote activity reveals player controls
- [x] Fifteen-second player overlay timeout
- [x] Cloudflare JSON data path with last-good local cache
- [x] Moving four-hour guide window and Jump to Now
- [x] Resume last watched channel
- [x] Debounced channel preview
- [x] Diagnostics and cache controls
- [ ] Android release prebuild and device validation

## Release progression

Closed Beta -> RC1 (tester fixes and tuning) -> Phoenix 2.0
